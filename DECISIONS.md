# Решения по работе №5

1. Строку разбираю через `split(";", -1)`. Второй аргумент сохраняет пустое последнее поле: строка `8;8;8;8;` должна закончиться ошибкой пятого значения. После разбора проверяю каждый элемент и сообщаю номер позиции, начиная с единицы.

2. Все нормы находятся в `TimesheetAnalyzer`: `MAX_HOURS = 30`, `DAY_NORM = 8`, `WEEK_NORM = 40`. Методы подсчёта проверяют и массив, переданный напрямую. Поэтому нельзя обойти ограничения, вызвав `total` без `parseHours`.
