# Практическая работа 6

Небольшая логическая задача с ветвлениями и конечным набором решений.

Маршрут согласования зависит от суммы, срочности, риска и персональных данных. Порядок условий и границы сумм проверяются в SelfCheck.

Сборка без Maven (JDK 17 или новее):

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr03.SelfCheck
```
