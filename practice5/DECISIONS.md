# Решения

1. В `split(";", -1)` сохраняю пустые поля, в том числе последнее. Каждое значение проверяется отдельно, а в сообщении об ошибке указан номер дня. Табель с ошибкой не участвует в расчёте.

2. Нормы находятся в `TimesheetAnalyzer`: `MAX_HOURS = 30`, `DAY_NORM = 8`, `WEEK_NORM = 40`. Методы расчёта проверяют и массив, переданный напрямую, чтобы ограничения нельзя было обойти без разбора строки.

Вариант 5: `76 % 8 + 1 = 5`. Верхняя граница равна 30 часам. Поэтому значение 17 из общего задания для этого варианта допустимо.
