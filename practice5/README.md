# Практическая работа 5

Строки, массивы, циклы и методы обработки данных.

Программа проверяет табель за пять дней и рассчитывает сумму часов, среднее и переработку. Проверки разбора строки и граничных значений находятся в SelfCheck.

Сборка без Maven (JDK 17 или новее):

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr02.SelfCheck
```
