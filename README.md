# Практическая работа №5

Строки, массивы и табель сотрудника. Последние цифры зачётки: 76. Вариант: `76 % 8 + 1 = 5`.

Вариант 5: в одном дне допускается от 0 до 30 часов включительно. Дневная норма остаётся 8 часов, недельная норма остаётся 40 часов. Число 30 здесь учебный параметр, а не оценка реальной продолжительности дня.

Нужен JDK 17 или новее. Maven и сторонние библиотеки не используются.

## Запуск в Windows

Откройте терминал в каталоге этой практической:

```powershell
.\run_selfcheck.ps1
.\run.ps1 -Entry Main -AppArgs @('--file', 'data/sample.csv')
```

Можно запустить `run_selfcheck.bat`. Для интерактивного ввода выполните `.\run.ps1 -Entry Main`.

## Запуск в Linux или macOS

```sh
sh run_selfcheck.sh
sh run.sh Main --file data/sample.csv
```

Скрипт собирает все файлы из `src` и `test`, затем запускает указанный класс. Самостоятельная сборка:

```sh
mkdir -p out
find src test -name '*.java' > out/sources.txt
javac --release 17 -encoding UTF-8 -d out @out/sources.txt
java -cp out ru.edu.pr02.SelfCheck
java -cp out ru.edu.pr02.BoundaryTests
```

Ответы на вопросы находятся в `REPORT.md`, два решения по устройству программы в `DECISIONS.md`. Диаграммы открываются в `DIAGRAMS.md` прямо на GitHub; отдельные изображения лежат в `diagrams/`. Фактический вывод проверок сохранён в `TEST_RESULTS.txt`.

Исходная практическая с заполненными ответами: `Практическая работа №5.pdf`. Сохранены исходные вопросы и оформление.
