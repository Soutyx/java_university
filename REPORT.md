# Ответы по работе №5

Вариант 5. Принимаются пять целых значений от 0 до 30. Часы сверх 8 увеличивают число дней с переработкой. Недельная переработка считается как `max(0, сумма - 40)`.

## Какая проверка нужна чаще всего

Пустое поле или буквы вместо часов отсекаются в цикле `parseHours`. Для ошибки одного дня показываю его номер, чтобы можно было сразу исправить строку. Если хотя бы один элемент неверен, расчёт не начинается.

## Где находится правило

Порог варианта записан в `MAX_HOURS` класса `TimesheetAnalyzer`. Там же находятся остальные нормы. Для изменения допустимого числа часов достаточно поменять константу и соответствующие граничные тесты.

## Связь диаграммы с кодом

После проверки числа полей диаграмма входит в цикл по пяти дням. На каждой итерации `parseHours` убирает крайние пробелы, переводит число в `int` и проверяет диапазон. После пятого корректного значения идут методы расчёта и вывод.

## Что меняется локально

Изменение верхней границы затрагивает `MAX_HOURS`. Менять разбор строки и формулу среднего при этом не нужно. При изменении числа дней потребуется поправить `DAYS` и текст сообщения о формате.

## Ошибка в предложенном фрагменте

При условии `i <= hours.length` последняя итерация обращается к несуществующему элементу `hours[5]`. У массива из пяти элементов последний индекс равен 4. В индексном цикле нужно `i < hours.length`; для суммирования в проекте используется цикл по значениям.

## Граничные проверки

| Ввод | Результат |
|---|---|
| `8;8;8;8;8` | сумма 40, среднее 8, переработка 0 |
| `9;8;7;10;8` | сумма 42, среднее 8.4, 2 дня и 2 часа переработки |
| `0;0;0;0;0` | принят, сумма 0 |
| `30;30;30;30;30` | принят, сумма 150 |
| `8;8;17;8;8` | принят по варианту 5 |
| `8;8;31;8;8` | ошибка позиции 3 |
| пустая строка | контролируемая ошибка |
| `8;8;8;8;` | ошибка позиции 5 |

Число 17 входит в собственные тесты, но по варианту 5 оно уже допустимо. Нельзя сохранять для него ожидание ошибки из общего правила 0..16.

Для защиты можно проследить строку `9;8;7;10;8`, затем заменить третий день на 31 и показать, почему отчёт не рассчитывается.
