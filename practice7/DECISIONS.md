# Решения

1. `Order` объединяет товары по id и разрешает изменения только в DRAFT. Если у одинакового id отличаются название или цена, добавление отклоняется. Новая позиция создаётся до замены старой, поэтому ошибка количества не меняет заказ.

2. `OrderItem` неизменяем, а `getItems` возвращает `List.copyOf(items)`. Внешний код не может поменять ни состав списка, ни количество в его элементах. Стоимость считается из текущих позиций через `BigDecimal`.

Вариант 5: параметр лимита суммы 30 принят как 30000 денежных единиц. Порог проверяется в `confirm`, равенство разрешено. Единицы и момент проверки в PDF не уточнены; это допущение решения. Сам порог записан в `Order.MAX_TOTAL`.
