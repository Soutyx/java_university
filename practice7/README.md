# Практическая работа 7

Первое полноценное ООП-приложение. Корпоративный заказ оборудования.

Заказ объединяет одинаковые товары, рассчитывает стоимость и запрещает изменения после подтверждения. SelfCheck проверяет позиции, ограничения и состояние заказа.

Сборка без Maven (JDK 17 или новее):

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr04.SelfCheck
```
